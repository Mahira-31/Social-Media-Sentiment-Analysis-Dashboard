# 🧠 Social Media Sentiment Analysis Dashboard

An interactive data visualization dashboard built using **Python** and **Tkinter**, designed to help users analyze sentiment data from various social media platforms such as Twitter, Facebook, and Instagram. This dashboard allows users to explore, filter, and visualize social media posts based on sentiment analysis.

---

## 📌 Features

- 🔍 **Search Functionality** – Search for posts by keywords or phrases (e.g., country, hashtag).
- 🧑‍💻 **Platform-Based Filtering** – Filter posts by social media platform (Twitter, Facebook, Instagram).
- 📊 **Dynamic Visualizations**:
  - Pie Chart: Sentiment Distribution (Positive, Neutral, Negative)
  - Bar Chart: Sentiment Comparison Across Platforms
  - Line Chart: Sentiment Trends Over Time
  - Word Frequency Chart: Common Words by Sentiment
- 📝 **Data Explorer** – Browse and explore raw social media posts, including text, user, sentiment, hashtags, and timestamps.
- 📤 **Export Data** – Export filtered or complete dataset to CSV for further analysis.
- 📅 **Real-Time Updates** – Real-time updates of all data visualizations based on selected filters and search criteria.
- ✅ **Responsive UI** with error handling and feedback.

---

## 🛠️ Technologies Used

- **Python 3**
- **Tkinter** – GUI framework
- **Matplotlib** & **Seaborn** – Data visualizations
- **Pandas** & **NumPy** – Data handling and processing
- **CSV** – Dataset format
